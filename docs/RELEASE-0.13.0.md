# Fusion 0.13.0

- Smaller in-game menu with a saved 60–95% size control, also available in launcher settings.
- Menu-only white watermark, including inventory and pause. No always-on gameplay logo.
- New saturation estimate, free look (hold Left Alt), FPS counter and coordinates modules, off until enabled.
- Removed the redundant Fusion profile selector and back-to-game footer. Official Minecraft Launcher handoff remains available.
- Readable, colored game output with streamed Log4j XML decoding.
- Custom update progress, including updates launched by older silent installers. Payload verification now happens during extraction.
- Privacy and terms pages inside Settings → About; proprietary notice for Fusion-owned material.
- Simpler README with pink screenshots and version artwork organized under updates.
- Public downloads and updates, without GitHub sign-in in this release.

Existing worlds, loader folders and the current 49-version selection are preserved. Saturation is client-side information and is not server-verified. Gameplay testing across every version/mod combination remains separate from the automated checks documented in VALIDATION.md.
